# 单聊真心话大冒险 Demo

一个可点击的本地前端演示，用于走查「聊天工具面板 → 小游戏 → 真心话大冒险」的单聊双角色轮流流程。

## 启动

```bash
npm install
npm run dev
```

构建校验：

```bash
npm run build
```

## 已覆盖的交互

- 两台 375 × 812 的 HelloTalk 聊天视图并列：左侧为林凡（发起人），右侧为 L10（受邀人）；两端共享同一局状态。
- 从聊天工具面板的「小游戏」进入；保留 36 问、猜拳、掷骰子，并新增真心话大冒险。
- 点击邀请即发起本局；统一安全题库由系统管理，不增加题包选择步骤。
- 林凡发起邀请，L10 在自己的聊天视图接受；林凡先选，完成后自动交换给 L10。当前回合的人才显示操作按钮，另一端只显示等待状态。
- 点击邀请后，聊天栏新增一张真心话大冒险邀请卡，发送方弹窗保留并进入「已发出邀请 / 等待对方进入」状态；受邀方不自动打开弹窗，点击卡片中的「打开游戏」后才进入邀请弹窗。邀请卡只承担邀请留痕和打开游戏入口，受邀方进入后双方弹窗实时显示双方头像并直接开始第一回合，不再增加双方分别点击「准备」的步骤。回合选择、题目、回答和跳过过程都留在双方同步弹窗内，不生成回合卡或答案消息。
- 弹窗左上角关闭即退出本局并同步展示结束状态；退出方看到“你已退出本局”，另一方看到“%@已退出本局，游戏已结束”，双方头像状态同步更新，同时聊天栏追加一行灰色“真心话大冒险已结束 · 共%@回合”。右上角最小化切换为聊天页左侧的小型游戏浮标，点击浮标恢复弹窗，不再显示底部进行中横幅。邀请、选择、题目和结束弹窗统一保持同一高度，标题、操作者、题型、题目、说明和操作区按层级留出阅读间距。弹窗内保留已完成回合的题目与答案历史；无固定三回合，双方轮流直至任一方退出。「再玩一次」直接开始新的第一回合。
- 桌面端提供双角色同步预览和可开关的 PRD 规则追溯标注；窄屏下依次展示两人的聊天视图。

这是前端交互原型，不代表已接入真实账号、消息、题库或风控服务。

## 首版题库与组件契约

题库配置位于 [src/prompt-bank.js](src/prompt-bank.js)：真心话与大冒险是两套独立题库，各 24 题。真心话全部是具体问题并仅接受文字回答；大冒险全部是可在当前聊天完成的明确动作，按文字、短语音、三表情组件出题。前台不展示题包；同一局内同一题型不重复，耗尽后才重新洗牌。

| 题目类型 | 数量 | 展示组件 | 提交规则 |
| --- | ---: | --- | --- |
| 文字 | 32 | 单行文字输入框 | 真心话或文字大冒险必填，点击「完成」 |
| 60 秒语音 | 8 | 当前题卡内原地录音条 | 最长 60 秒，录制后直接发送；不提供文字替代 |
| 三表情 | 8 | HT 风格表情抽屉：直接展示的 8 列表情网格 | 必须选满 3 个，再点击「完成」 |

首版不放图片、视频、位置、联系人、线下行为或需要验证完成的挑战，避免聊天能力与题目要求脱节。

## 多语言检查

多语言规则已补全：本期沿用客户端现有支持语言清单，不新增语言种类；界面文案缺失时回退应用默认语言，题目缺失时回退题目配置的默认语言。当前 Demo 的客户端和题库后台仍以中文硬编码为主，正式翻译、语言切换和异常态文案尚未交付，因此仍不能判定为“多语言完整”。逐项覆盖清单见 [LOCALIZATION_MATRIX.md](LOCALIZATION_MATRIX.md)；该清单也是后续本地化验收范围，不代表已经完成翻译。
