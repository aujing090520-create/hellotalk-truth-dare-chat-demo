# 单聊真心话大冒险 Demo

一个可点击的本地前端演示，用于走查「聊天工具面板 → 小游戏 → 真心话大冒险」的单聊双角色轮流流程。

## 启动

```bash
npm install
npm run dev
```

构建校验：

```bash
npm run build
```

## 已覆盖的交互

- 两台 375 × 812 的 HelloTalk 聊天视图并列：左侧为林凡（发起人），右侧为 L10（受邀人）；两端共享同一局状态。
- 从聊天工具面板的「小游戏」进入；保留 36 问、猜拳、掷骰子，并新增真心话大冒险。
- 点击邀请即发起本局；统一安全题库由系统管理，不增加题包选择步骤。
- 林凡发起邀请，L10 在自己的聊天视图接受；林凡先选，完成后自动交换给 L10。当前回合的人才显示操作按钮，另一端只显示等待状态。
- 邀请被接受后，聊天记录只保留一张固定的开局卡，不新增游戏卡；底部「真心话大冒险进行中」条同步当前回合，并让当前玩家直接选择、回答或完成；正常文字聊天不受影响。题库为每题声明回答能力：文字、短语音或选择表情。短语音题仅提供原地录音与发送，表情挑战在游戏页提供最多选 3 个的快捷表情选择器，不依赖聊天工具栏；回答以带题型、回合和真实问题/挑战引用的原生聊天气泡沉淀。游戏结束时新增一条静态系统消息；回合选择页和题目页都支持结束本局，另支持不想回答（同步拒答并交棒）和再来一局。
- 聊天记录中沉淀邀请卡、回合卡、回答结果和结束卡；无固定三回合，双方轮流直至任一方结束。
- 桌面端提供双角色同步预览和可开关的 PRD 规则追溯标注；窄屏下依次展示两人的聊天视图。

这是前端交互原型，不代表已接入真实账号、消息、题库或风控服务。

## 首版题库与组件契约

题库配置位于 [src/prompt-bank.js](src/prompt-bank.js)：真心话与大冒险是两套独立题库，各 24 题。真心话全部是具体问题并仅接受文字回答；大冒险全部是可在当前聊天完成的明确动作，按文字、短语音、三表情组件出题。前台不展示题包；同一局内同一题型不重复，耗尽后才重新洗牌。

| 题目类型 | 数量 | 展示组件 | 提交规则 |
| --- | ---: | --- | --- |
| 文字 | 32 | 单行文字输入框 | 真心话或文字大冒险必填，点击「完成」 |
| 60 秒语音 | 8 | 当前题卡内原地录音条 | 最长 60 秒，录制后直接发送；不提供文字替代 |
| 三表情 | 8 | HT 风格表情抽屉：直接展示的 8 列表情网格 | 必须选满 3 个，再点击「完成」 |

首版不放图片、视频、位置、联系人、线下行为或需要验证完成的挑战，避免聊天能力与题目要求脱节。

## 多语言检查

当前 Demo 的客户端和题库后台仍以中文硬编码为主，PRD 中虽然已标注多语言资源，但正式翻译、语言切换和异常态文案尚未交付，因此不能判定为“多语言完整”。逐项覆盖清单见 [LOCALIZATION_MATRIX.md](LOCALIZATION_MATRIX.md)；该清单也是后续本地化验收范围，不代表已经完成翻译。
